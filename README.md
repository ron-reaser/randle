# Randle

This [Discord](https://discord.com) bot provides tabletop gaming randomization features supporting virtual dice and cards. It is open source under the MIT license and free to serve for your own community.

The bot is hand-written in strict [TypeScript](https://www.typescriptlang.org/) for [Node.js](https://nodejs.org/en/) using the [Discord.js](https://discord.js.org) library. It is intended for running as a web service on a low-cost or no-cost cloud platform.
